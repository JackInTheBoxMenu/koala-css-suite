# koala-css-themeplugins
Suite of CSS snippets I've made or edited.
## Installation
Grab the .css file in Releases, or download `koala-css-suite.theme.css` from Main.
### BetterDiscord
1. Go to User Settings
2. Navigate to or search for **Themes** in the **BetterDiscord** category
3. Click on the folder icon, labeled **Open Theme Folder**
4. Drag and drop the .css file into the file path that opened

## Editing Settings
You can easily edit the CSS suite by pressing the **Edit** button in **Themes**, then following the instructions within the .css file.
Alternatively, you can directly open the .css file itself in an external editor like Notepad++, which may be preferred.

You can disable anything by commenting it out, as this was made to be as modular as possible for easy commenting of features/options.
To comment a setting out, add `/*` at the beginning, and `*/` at the end of a setting, like this:

```
/*examplesetting*/
```
or like this:
```
/*
examplesetting
*/
```
